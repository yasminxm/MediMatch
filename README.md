# MediMatch

MediMatch is an information retrieval search engine that matches user symptoms to possible diseases or causes and provides recommended precautions to take.

## Features

- Matches symptoms to relevant medical conditions
- Suggests possible causes based on symptom input
- Provides precautionary advice
- Fast information retrieval system
- Python-based implementation

## Files

- `medimatch.py` – Main Python program
- `HealthSearchEngineData` – Dataset used for search results

## Purpose

This project was created to explore information retrieval, search engine logic, and healthcare-focused data matching using Python.

## How to run

1. Open the notebook in Google Colab
2. Run all cells
3. Enter a symtom when prompted

## Technologies Used

- Python
- Google Colab
- Data Processing
- Search Algorithms
